Collab Sans is a clean, rounded neo-grotesque typeface family across 18 styles (9 weights from Thin to Black, with matching true italics). Semicircular tangent caps meet proportional concave fillets.

Styles: 18 (9 Upright + 9 Italic)
Glyphs: 2,548 per font
Formats: TTF, OTF, WOFF2
License: SIL OFL 1.1 (Free for Personal & Commercial)

I am not a professional developer or traditional type designer. My background is rooted in organizational systems, finance, and building scalable enterprise workflows as a citizen developer. For me, minimalism is not a design preference—it is a way of living and working: stripping away noise so function and clarity become obvious.

That obsession with clarity drew me directly to Rasmus Andersson’s Inter—the undisputed benchmark of modern digital interface typography. But across product interfaces, data dashboards, and mobile surfaces, I felt a recurring void: I wanted the mathematical precision and micro-legibility of Inter, but with the warmth, friendliness, and understated minimalism that only genuinely rounded terminals can bring.

Rather than drawing outlines by hand, I built this entire font family using Antigravity (Google's agentic AI coding environment). Together, we engineered an algorithmic geometry engine in Python that traversed Inter's 2,548 glyphs contour-by-contour:

  • Tangent-Continuous Semicircular Terminals: Curving stroke ends with exact circular caps ($R = 0.50 \times W$) across horizontal, vertical, and $9.4^\circ$ italic terminals.
  • Ink-Trap Preserved Fillets: Applying proportional inner fillets ($R = 0.14 \times W$) to prevent ink clogging and optical muddiness at small 11px–14px UI sizes.
  • Zero Feature Compromise: Retaining every kerning pair, tabular figure (`tnum`), slashed zero, fraction, and stylistic set from the original Inter.

Use Collab Sans on the Web

Self-host with CSS or link directly in your web applications.

/* Include in your CSS */
@font-face {
  font-family: 'Collab Sans';
  src: url('./fonts/woff2/CollabSans-Regular.woff2') format('woff2');
  font-weight: 400;
}

body {
  font-family: 'Collab Sans', -apple-system, sans-serif;
}
